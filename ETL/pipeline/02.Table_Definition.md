## Column Naming Conventions

* **ID Columns**: `_ID` suffix (e.g., EMP_ID, PRSNL_ID)
* **Code Columns**: `_CD` suffix (e.g., LCNS_CD, SCH_CD)
* **Name Columns**: `_NM` suffix (e.g., LCNS_NM, SCH_NM)
* **Date/Time Columns**: `_DT`, `_DTT` suffix (e.g., MOD_DTT, CAM_DT)
* **Status/Flag Columns**: `_YN` suffix (e.g., REG_YN, LAST_SCHLST_YN)
* **Month Count Columns**: `_MTH_CNT` suffix
* **Amount Columns**: `_AMT` suffix

## Common Columns

Columns included commonly across all tables:

* **EMP_ID**: Employee unique identifier (includes company-specific prefix: f/q/a)
* **MOD_PRSN**: Last modifier
* **MOD_DTT**: Last modification date/time
* **TZ_CD / TZ_DTT**: Timezone information
* **NOTE**: Remarks / Special notes
