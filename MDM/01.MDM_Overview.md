# 📂 Case Study: Heterogeneous Data Integration & Master Data Management (MDM)
> **Topic:** Building a Cost-Effective Master Data Management System for 10+ Affiliates Using BI-Matrix

## 1. Executive Summary
This project was conducted to solve the **Data Fragmentation** issue commonly occurring in enterprise environments. As more than 10 affiliates used different ERP systems, there was an inconsistency in HR data standards. To resolve this, rather than purchasing expensive MDM solutions, we leveraged the existing infrastructure, **BI-Matrix**, to design a self-built mapping system. Through this, we synchronized group standard codes with each affiliate's local codes, enabling integrated enterprise-wide analytics.

---

## 2. Problem Statement
* **Data Silos:** Due to different code systems across affiliates, accumulating group-wide workforce analytics required a vast amount of time.
* **Cost Barrier:** Adopting a commercial MDM solution entailed high initial setup and maintenance costs, resulting in a heavy financial burden.
* **Analytical Limitations:** Human errors occurred during manual data cleaning and mapping processes, making real-time analysis impossible.

---

## 3. Implementation: Integrated HR Master Code Interface
By utilizing the scripting capabilities of the pre-implemented **BI-Matrix** platform, a dynamic management screen capable of data retrieval and manipulation (CRUD) was developed.

### 🌟 Key Features
* **Dual Grid Synchronization (Recursive Mapping):** Features a self-referencing structure within a single table. Selecting a category (e.g., Job Rank, Education) in the **Top Level Grid** immediately filters and displays corresponding detailed mapping information in the **Detail Grid** below.
* **Dynamic Metadata Header:** Since management items vary depending on code types, a script was implemented to update column names (`VALUE1`~`VALUE10`) of the bottom grid in real-time to align with the selected category.
* **Direct Data Control:** Users can modify mapping logic directly on the screen using **Search, Add, Save** buttons, ensuring autonomy in data management.

## 4. Technical Architecture

### Database Schema: `Integrated_Master_Code`
Designed with scalability in mind, this table structure can accommodate attribute values from various affiliates without requiring separate schema modifications.

| Column Name | Type | Nullable | Description |
| :--- | :--- | :--- | :--- |
| `SEQ` | BIGINT | No | Primary Key (PK) for record identification |
| `CATEGORY_CODE` | VARCHAR(20) | No | High-level category identifier (e.g., `RankCl`, `GenderCl`) |
| `DETAIL_CODE` | VARCHAR(30) | No | Detailed item code within a category |
| `CATEGORY_NAME` | VARCHAR(20) | Yes | Category name to be displayed on the UI |
| `DETAIL_NAME` | VARCHAR(100) | Yes | Standardized item name |
| `VALUE1 ~ VALUE10` | VARCHAR(Varies) | Yes | **Mapping Fields**: Stores local codes and attribute values per affiliate |
| `SORT_ORDER` | INT | Yes | Display order on screen |
| `UPDATED_BY` | VARCHAR(10) | Yes | Modifier ID (for audit trail) |
| `UPDATED_AT` | VARCHAR(20) | Yes | Modification Timestamp (for audit trail) |

## 5. Engineering Impact & Business Value

### 🚀 Technical Excellence: "Scalable Design"
Moving beyond a simple management tool, this system serves as a configuration tool for the Gold Layer in the data pipeline's **Medallion Architecture**. Even when new affiliates are added, data integration can be accomplished simply by adding rows on the screen without developer intervention.

### 💰 Strategic Cost Reduction
By building in-house instead of using commercial solutions, the following achievements were made:
* **100% Reduction in Solution License Costs**
* **Over 90% Reduction in Report Generation Time** (compared to manual Excel cleaning)
